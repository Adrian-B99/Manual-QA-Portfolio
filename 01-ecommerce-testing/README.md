# E-commerce Website – Manual Testing Project
## Project Overview

This project focuses on manual testing of an e-commerce web application. The goal was to verify the functionality of the application, identify defects, and document test results using a structured testing approach.

This is an independent portfolio project created for learning purposes to demonstrate my practical skills in software testing and quality assurance.

## Application Under Test
- **Application:** SauceDemo
- **Application Type:** E-commerce web application
- **Testing Type:** Manual Testing
- **Testing Environment:** Web browser
- **Project Status:** Completed

## Scope of Testing
### The following areas were covered during testing:
- Login and logout
- Product listing and product details
- Sorting products
- Adding and removing products from the shopping cart
- Shopping cart functionality
- Checkout process
- Form validation and negative scenarios

## Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- Exploratory Testing

## Tools Used
- **Microsoft Excel** – test cases and test execution documentation
- **Jira** – defect tracking and bug reporting
- **Google Chrome** – test execution.
- **PicPick** – screenshot capture and image annotation.
- **GitHub** – project documentation and portfolio

## Test Documentation
### The project includes the following deliverables:
- **Test Plan** – scope, objectives, approach, and testing criteria
- **Test Cases** – test scenarios, preconditions, steps, and expected results
- **Test Execution** – actual results and test statuses
- **Bug Reports** – documented defects with reproduction steps and supporting evidence
- **Test Summary Report** – overview of test execution results and identified issues

## Test Execution Summary
- **Total test cases:** 39
- **Passed:** 30
- **Failed:** 9
- **Not Run:** 0
- **Bugs reported:** 9

## Key Findings
During testing, I documented defects and inconsistencies between actual and expected application behavior.

Each reported defect includes a description, preconditions where applicable, steps to reproduce, expected result, actual result, severity or priority where appropriate, and supporting screenshots when available.
