# Junior Manual QA Portfolio

A portfolio of practical manual testing projects demonstrating my skills in test case design, test execution, bug reporting, SQL data validation, and REST API testing.

## About Me

My name is Adrian I am an aspiring **Junior QA Tester** developing my skills in manual software testing and quality assurance through independent testing projects and continuous learning.

I am building my QA knowledge through the **Tester Oprogramowania od Podstaw: Praktyczny Bootcamp QA course by Rafał Podraza**, along with supplementary learning materials and YouTube tutorials.

My goal is to develop a strong foundation in software testing, improve my analytical skills, and gain practical experience in quality assurance.

## Skills & Tools

- **Manual Testing:** Functional testing, positive and negative scenarios, exploratory testing
- **Test Documentation:** Test cases, test execution, expected vs. actual results
- **Bug Reporting:** Clear issue descriptions, reproduction steps, and supporting evidence
- **API Testing:** REST API requests, HTTP methods, status codes, response validation, authentication
- **SQL:** Basic SQL queries (SELECT, WHERE, ORDER BY, GROUP BY, HAVING, JOIN, aggregate functions)
- **Tools:** Postman, Microsoft Excel, GitHub, Jira

## Projects

### 01 — E-commerce Application Testing

**Scope:** Manual testing of an e-commerce web application.

- Test planning and test case design
- Functional testing of login, product listing, shopping cart, and checkout
- Positive and negative test scenarios
- Test execution and result documentation
- Bug reporting with supporting screenshots

**Tools:** Microsoft Excel, GitHub, Jira (where applicable)

[View E-commerce Testing Project](./01-ecommerce-testing/README.md)

### 02 — SQL Testing

**Scope:** Data validation and SQL query testing using a sample database.

- Filtering and sorting records
- Using aggregate functions and grouping data
- Testing data relationships with INNER JOIN and LEFT JOIN
- Validating data consistency and identifying potential data quality issues
- Documenting test cases and actual results

**Tools:** MariaDB, XAMPP, phpMyAdmin, Microsoft Excel

[View SQL Testing Project](./02-sql-testing/README.md)

### 03 — REST API Testing

**Scope:** Manual API testing of the Restful Booker demo API.

- Testing GET, POST, PUT, PATCH, and DELETE requests
- Verifying HTTP status codes and response bodies
- Testing authentication and authorization scenarios
- Validating positive and negative scenarios
- Documenting test cases and actual results

The project uses a shared demo environment where test data may change or be reset periodically. Authentication tokens are temporary, so test execution may require fresh data and a newly generated token.

**Tool:** Postman, Microsoft Excel

[View API Testing Project](./03-api-testing/README.md)
